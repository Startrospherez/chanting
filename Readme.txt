☀️โฟลเดอร์นี้คือโปรเจค Interactive Web app of รวมบทสวดมนต์ โดยมีลักษณะการใช้งานสไตล์หนังสือสวดมนต์ คือเปิดอ่านเป็นหน้าๆ หรือเลื่อน หรือ มีระบบเลื่อนอัตโนมัติ.

มีหน้า UI พื้นฐาน ดูเรียบง่ายที่สุด zen ui minimal, beige, เรียบ, ธรรมชาติ

เวลาเปิดโหมดสวดมนต์มีแต่ตัวหนังสือบทสวดเท่านั้น แล้วระหว่างสวดสามารถปรับแต่ง ui ได้ระบบคล้าย player youtube

มีระบบเปิด-ปิดเฉพาะท่อนบาลี หรือไทย หรือเปิดทั้งสองได้. ภาษาบาลีเลือกได้ว่าเป็นบาลีอักษรไทย (ที่จะมีพินทุ-นิคหิต) หรือบาลีสะกดแบบไทย (มีสระอะ ะ และเคริ่องหมายยามักการ เขียนด้วย เป็นต้น).

มีระบบ admin แยกสำหรับผม เพื่อให้สามารถเปิดโหมด เพิ่ม-ลด-ปรับแต่งรายการบทสวดมนต์ได้. เบื้องต้น มีช่องสำหรับกรอก Password ว่า Karn เพื่อเปิดโหมดผู้ดูแล

เป้าหมายสำหรับผู้ใช้ที่ในการเปิดดูบทสวดมนต์แล้วสวดไปด้วย. มีโหมดถนอมสายตา
