Architecture Overview

1. แกนหลัก (index.html)

ควบคุมหน้าจอหลัก ระบบถนอมสายตา และการสลับโหมดสวดมนต์ พร้อมเปิดช่องเชื่อมต่อโมดูลเสริมภายนอกโดยไม่ต้องแก้ไฟล์หลักซ้ำ

2. ฐานข้อมูลกลาง (chants-data.js)

นำเข้าบทสวดผ่าน JSON แบบสแต็กต่อท้าย และกดปุ่มบันทึกเป็นไฟล์ chants-data.js เพื่อแชร์ข้ามเครื่องในโฟลเดอร์เดียวกันได้ทันที

3. โมดูลเสริม (module-1.js, module-2.js)

แยกไฟล์อิสระสำหรับระบบลิ้นชักเพลย์ลิสต์ด้านซ้าย และระบบ Split-Screen แก้ไขบทสวดสดพร้อมปรับขนาดฟอนต์รายบรรทัด
